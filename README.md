# Engineering Universe

Interactive 3D knowledge graph for software engineering, networking, cloud, DevOps and security.

## MVP
- Search concepts and fly the camera to matching nodes
- Rotate, zoom and explore a 3D knowledge graph
- Open a concept detail panel and discover related concepts
- Reusable, typed concept and relationship data

## Stack
Next.js, TypeScript, React, three.js and 3d-force-graph.

## Local development
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Roadmap
1. Expand and validate the concept graph
2. Add deep-linked concept pages and content schema
3. Build deterministic event-based simulation engine
4. Add interactive HTTP, DNS, TCP and TLS walkthroughs
5. Add isolated labs and learning progress

This is an early interactive prototype; relationships and explanations are illustrative, not protocol-level simulations.
