# Learning path implementation batches

## Batch 1 — From URL to Web Page
Status: Implemented in the development branch, awaiting CI and browser verification.

Seven authored lessons:
1. DNS and URL parsing
2. IP addressing
3. Routing
4. TCP and HTTP/3 distinction
5. TLS and certificates
6. HTTPS and HTTP requests
7. Browser rendering

Each lesson includes a learning objective, explanation, practical exercise, common misconception, and graded question. The UI stores completion in browser localStorage; progress is not synced across devices. This is not a secure certification or examination system.
