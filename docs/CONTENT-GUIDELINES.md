# Content quality and simulation fidelity

## Catalogue
The initial catalogue is an index, **not** 150+ fully written lessons. Generic descriptions are explicitly placeholders. Each entry requires an editorial review before being marked complete.

## Simulation fidelity
All current scenarios are **illustrative deterministic walkthroughs**, not packet captures or emulations. Timing is an animation timeline, not measured network latency. Never claim protocol fidelity beyond implemented and validated behavior.

## Future content schema
Concept content should include: learning objectives, explanation, prerequisite IDs, typed relationships, message-level examples, variations, failure cases, accessibility text, standards references, and review date.

## Validation checklist
- No orphan or duplicate concept IDs
- Every relationship endpoint resolves
- Every learning-path ID resolves
- Every simulation actor and event is valid
- No misleading protocol sequencing or claims
- UI is keyboard accessible and respects reduced motion
